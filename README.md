# Luis Schiazza — CV

Projeto desenvolvido como parte da disciplina **Projeto Integrador II**.

## Sobre o projeto

O **luis-schiazza-cv** é um projeto acadêmico desenvolvido com o objetivo de aplicar, na prática, os conhecimentos adquiridos durante o curso.

A proposta consiste no desenvolvimento de uma aplicação voltada à apresentação de informações profissionais e acadêmicas, funcionando como um currículo digital organizado, acessível e de fácil visualização.

Além da apresentação profissional, o projeto também busca aplicar conceitos relacionados à estruturação de aplicações, organização de código, versionamento e boas práticas de desenvolvimento.

## Objetivo

O principal objetivo do projeto é desenvolver uma solução capaz de apresentar, de maneira clara e estruturada, informações relacionadas ao perfil profissional, incluindo:

- Formação acadêmica;
- Experiências profissionais;
- Conhecimentos técnicos;
- Habilidades;
- Projetos desenvolvidos;
- Informações para contato.

## Contexto acadêmico

Este projeto foi desenvolvido para a disciplina **Projeto Integrador II**.

A atividade tem como finalidade integrar conhecimentos adquiridos ao longo do curso por meio do desenvolvimento de uma aplicação prática, permitindo aplicar conceitos técnicos em um projeto com finalidade real.

As tecnologias utilizadas no desenvolvimento serão documentadas conforme a evolução do projeto.

## Estrutura do projeto

O repositório será organizado de forma modular, buscando manter uma estrutura clara e facilitar a manutenção e evolução da aplicação.
